# Dante’s Ascent

A short vertical 2D platformer demo set in Hell, created as a portfolio piece.

**Play:** [itch.io link]  
**Engine:** Godot 4

---

## About

You play as Dante climbing upward through a hand-crafted section of Hell. Reach the top in a single run. Death returns you to the beginning.

The demo focuses on atmosphere, hand-drawn art, and vertical platforming. The tone draws from Dante’s *Inferno* and the illustrations of Gustave Doré — monumental, cold, and oppressive rather than gory.

This is a self-contained vertical slice, not a full game.

---

## Features

- Vertical hand-crafted climb (target run time: 6–10 minutes)
- Three enemy types with simple combat
- Side paths that are darker and more dangerous
- Single-run power-ups
- Hand-drawn art and environments
- Asymmetric vignette that emphasizes upward movement

## Running the Project

1. Clone or download this repository
2. Open the project in **Godot 4.x**
3. Press F5 (or the Play button)

A Windows build will also be available on itch.io.
